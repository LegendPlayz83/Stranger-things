This is a website on the series Stranger Things to test your knowledge of Hawkins. A perfect quiz for a spooky October!

It is a website made with HTML, CSS and JavaScript. 
<br>

<h3>Running It</h3>
The website is simply deployed on GitHub Pages and can be run using this link: <br>
(https://legendplayz83.github.io/Stranger-things/)

<h3>Tech Stack</h3>
-Uses HTML to form the basic structure of the site, organising the webpage into different sections, including the navigation bar, start screen, quiz area, result screen, and footer. It also links the CSS file for styling and the JavaScript file for quiz functionality <br>
<br>
-Uses CSS to design and style the Stranger Things Quiz website. It creates the dark background and red accents that are inspired by the show's theme, while also controlling the colours, fonts, spacing, alignment, and sizes of different elements. (this is a lot ngl) <br>
<br>
-Uses JavaScript to add functionality and interactivity to the Stranger Things Quiz website. It stores the quiz questions, multiple-choice options, and correct answers in an array. The program displays one question at a time, checks the selected answer, highlights correct answers in green and incorrect answers in red, and updates the total score. (try to get as much as you can XD)
